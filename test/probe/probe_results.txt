=== G. Temporal ease on maskPath keys (prd.md 7, tier 1) ===
AE ease = influence (%) + speed (value-units/sec). Only influence
normalizes across control points; see the .rbj ease param question.
  key 1 in : 1 dim, [0] speed=0 influence=16.667
  key 1 out: 1 dim, [0] speed=1 influence=16.667
  key 2 in : 1 dim, [0] speed=0 influence=91.176
  key 2 out: 1 dim, [0] speed=0 influence=100
  key 3 in : 1 dim, [0] speed=1 influence=16.667
  key 3 out: 1 dim, [0] speed=0 influence=16.667

Note the dimension count above. If ease is 1-D on a shape property,
a single shape-wide ease is what .rbj must store.
