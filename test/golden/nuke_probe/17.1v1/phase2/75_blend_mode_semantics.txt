Which `bm` value is union, difference, intersection - by rendering.

Case 73 showed `bm` is an opaque float and the Python API never
names it. The only authority is what the node actually composites,
so build two overlapping squares and sample the alpha in three
places while sweeping the second shape's blending mode.

A covers (100,100)-(300,300), B covers (200,200)-(400,400).
Sample points: A only (150, 150), overlap (250, 250), B only (350, 350).

Reference readings, with B at its default:
  union        -> A 1, overlap 1, B 1
  difference   -> A 1, overlap 0, B 0   (B cuts A away)
  intersection -> A 0, overlap 1, B 0
